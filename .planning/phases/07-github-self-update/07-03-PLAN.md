<objective>
Wire the update check into the running app: a `updateCheckProvider` FutureProvider that fires the cold-start check, and a ScanScreen `ref.listen` that, when a newer version is detected, shows an update dialog naming the version with Skip and Update actions. Update downloads the APK with a live progress indicator and launches the installer; Skip persists the version so it never re-prompts. Extend the ScanScreen widget test to prove the dialog appears.
