## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4dp | Icon-to-label gap, chip internal padding |
| sm | 8dp | ListTile internal spacing, AppBar action spacing |
| md | 16dp | Default screen horizontal padding, row gap between angle rows |
| lg | 24dp | Vertical padding around angle readout block |
| xl | 32dp | Top/bottom inset of instrument screen body |
| 2xl | 48dp | Not used in Phase 4 |
| 3xl | 64dp | Not used in Phase 4 |

Exceptions:
- Angle readout touch area: minimum 44dp height per row (accessibility tap target)
- Zero button minimum touch target: 44×44dp (Material recommended minimum)
- FAB uses default Flutter FAB sizing (56dp)

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Angle readout | 80sp | w700 (bold) | 1.0 | angleX and angleY values; dominates instrument screen |
| AppBar title | 18sp | w400 (regular) | 1.2 | Screen titles ("Scan" / "Inclinometer") |
| Body / axis label / device name | 16sp | w400 (regular) | 1.5 | ListTile primary text (device name), "X" / "Y" prefix labels next to readout |
| Secondary / buttons / chips | 13sp | w400 (regular) | 1.4 | dBm value, AppBar chip label, battery percentage, "Zero X" / "Zero Y" / "Sim. Disconnect" button labels |

**Declared sizes: 4 — 80sp, 18sp, 16sp, 13sp.**
**Declared weights: 2 — w700 (angle readout only), w400 (all other text).**

**Tabular numerals:** Angle readout (80sp) uses `fontFeatures: [FontFeature.tabularFigures()]`. This prevents layout jitter as digits change width at live update rates (satisfies INST-07).

**Angle format:** `±NNN.NN°` — sign always shown (+ or −), 3 integer digits zero-padded, 2 decimal places, degree symbol appended. Example: `+012.34°`, `−003.00°`. Fixed character width prevents horizontal layout shift.

## Color

Dark-first theme. Base: `ThemeData.dark()` with explicit overrides below.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `Color(0xFF121212)` | Scaffold background, screen background |
| Secondary (30%) | `Color(0xFF1E1E1E)` | AppBar background, ListTile background, card surfaces |
| Accent (10%) | `Color(0xFF1E88E5)` — Material Blue 600 | FAB background, scan chip (scanning state), tappable device row highlight |
| Destructive | `Color(0xFFD32F2F)` — Material Red 700 | Connection chip: disconnected / error state; Zero button disabled state uses opacity, not this color |

**Connection chip — full state map (source: CONTEXT.md D-08, D-09):**

| ConnectionStatus | Chip color | Label |
|-----------------|-----------|-------|
| idle | `Color(0xFF757575)` — Grey 600 | "Idle" |
| scanning | `Color(0xFF1E88E5)` — Blue 600 | "Scanning" |
| connecting | `Color(0xFFFFA000)` — Amber 700 | "Connecting…" |
| connected | `Color(0xFF43A047)` — Green 600 | "Connected" |
| reconnecting | `Color(0xFFF57F17)` — Amber 900 | "Reconnecting…" |
| disconnecting | `Color(0xFFD32F2F)` — Red 700 | "Disconnecting…" |
| disconnected | `Color(0xFFD32F2F)` — Red 700 | "Disconnected" |
| error | `Color(0xFFD32F2F)` — Red 700 | "Error" |

Chip foreground text: always `Colors.white` (sufficient contrast on all chip colors above).

Accent reserved for: FAB, scan-state chip when scanning, pressed device row splash. Never used for status indicators (those use the chip color map above).

**Stale data state (D-08):** When `instrumentDataProvider` emits `null`, the angle readout block (both rows, labels, and values) animates to `opacity: 0.40` over 300ms using `Curves.easeOut`. The values remain rendered at reduced opacity — they are reference-only. Connection chip simultaneously switches to the red disconnected color. No other elements change.

## Component Specifications

### Scan Screen (`lib/ui/scan_screen.dart`)

**AppBar:**
- Title: "Scan" (AppBar title, 18sp/w400)
- Right of title (or subtitle row): scan-state chip (see chip spec below)
- No back button (this is the root screen in Phase 4 standalone; Phase 5 will wire go_router)

**Scan state chip (SCAN-04 / D-06):**
- Widget: `Chip` with `backgroundColor` from connection chip color map (idle/scanning/error states relevant here)
- Label: see chip state map above
- Size: compact — `visualDensity: VisualDensity.compact`, `labelStyle` 13sp/w400
- Positioned: as `AppBar.bottom` via `PreferredSize` wrapping a left-aligned `Padding` — NOT a full banner

**FAB (SCAN-01 / D-05):**
- Icon: `Icons.bluetooth_searching` when idle/stopped; `Icons.stop` when scanning
- Background: Accent Blue 600 when idle; `Colors.red[400]` when scanning (stop affordance)
- OnPressed: calls `connectionNotifierProvider.notifier.startScan()` or `.stopScan()`
- Label: none (icon-only FAB)

**Device list (SCAN-02, SCAN-03, SCAN-05 / D-07):**
- Widget: `ListView.builder` over `scanResultsProvider`
- Filter: only show devices where `name != null && name.isNotEmpty` (SCAN-03)
- Each row: `ListTile`
  - `leading`: RSSI icon (see RSSI icon spec below)
  - `title`: device name, 16sp/w400, `Colors.white`
  - `trailing`: raw dBm value, 13sp/w400, `Colors.white70` (e.g. `"−72 dBm"`)
  - `onTap`: calls `connectionNotifierProvider.notifier.connect(device.id)`
- Empty state (no devices found): centered `Column` with icon `Icons.bluetooth_disabled` at 48dp, 12dp gap, "No devices found" (16sp/w400/`Colors.white54`), 8dp gap, "Start scanning to discover devices." (13sp/w400/`Colors.white38`)

**Error state (ConnectionStatus.error):**
- Below the device list (or below the scan-state chip when the list is empty), show a `Text` widget with string key `scan_error_body`: "Could not start scan. Check Bluetooth is enabled."
- Style: 13sp/w400, `Colors.white70`, `textAlign: TextAlign.center`
- Horizontal padding: md (16dp) on each side
- The scan-state chip label remains "Error" (chip alone is insufficient — this body text is the solution path)

**RSSI icon spec:**
- `-60 dBm or better` → `Icons.signal_wifi_4_bar` (full signal)
- `-75 to -61 dBm` → `Icons.network_wifi_3_bar`
- `-85 to -76 dBm` → `Icons.network_wifi_2_bar`
- `-86 dBm or worse` → `Icons.network_wifi_1_bar`
- Icon color: `Colors.white70`; size: 20dp

### Instrument Screen (`lib/ui/instrument_screen.dart`)

**AppBar:**
- Title: "Inclinometer" (18sp/w400)
- Actions (left to right):
  1. Battery indicator (D-04): `Icons.battery_full` / `battery_6_bar` / `battery_3_bar` / `battery_0_bar` icons (thresholds: >75% full, >40% 6-bar, >15% 3-bar, else 0-bar) + `Text("${battery}%")` at 13sp/w400. Both `Colors.white`. Gap between icon and text: 4dp.
  2. Connection chip (D-09): `Chip` with color from chip state map above. Always visible.
  3. Debug button (D-13, `kDebugMode` only): `TextButton` or overflow `PopupMenuButton` item, label "Sim. Disconnect", calls `(ref.read(bleManagerProvider) as MockBleManager).simulateDisconnect()`. Only compiled/shown when `kDebugMode == true`.

**Angle readout block (D-01, D-02, D-03 / INST-02, INST-03, INST-07):**
- Widget: `AnimatedOpacity` wrapping a `Column` of two `_AngleRow` widgets
- `opacity`: 1.0 when live (`DeviceState != null`); 0.40 when stale (`DeviceState == null`)
- Duration: `Duration(milliseconds: 300)`, curve: `Curves.easeOut`
- Positioned: vertically centered on screen with `xl` (32dp) top/bottom padding

**Each angle row (`_AngleRow`):**
- Layout: `Row` with `MainAxisAlignment.spaceBetween`
- Left: axis label `Text("X")` or `Text("Y")`, 16sp/w400, `Colors.white54`
- Center: angle value `Text(formatted)`, 80sp/w700, `Colors.white`, `fontFeatures: [FontFeature.tabularFigures()]`, format `±NNN.NN°`
- Right: `ElevatedButton` labeled "Zero X" or "Zero Y", 13sp/w400
  - Enabled only when `ConnectionStatus == connected` (D-12)
  - OnPressed fires silently — no snackbar, no animation (D-11): calls `connectionNotifierProvider.notifier` method that sends `BleProtocol.ZERO_X` or `ZERO_X_Y`
  - Disabled style: default Material disabled appearance (opacity ~0.38 on label and background)
  - Minimum size: `Size(88, 44)` to meet touch target (D-03)
  - Button row height: minimum 44dp (accessibility)

**Stale label overlay (CONN-05):**
- When stale (`DeviceState == null`): `Text("DISCONNECTED", style: TextStyle(fontSize: 13, fontWeight: FontWeight.w400, color: Color(0xFFD32F2F), letterSpacing: 1.5))` shown below the (faded) readout block. Appears with the same 300ms `AnimatedOpacity` transition.

**Disconnect button (CONN-02):**
- `OutlinedButton` at bottom of screen: label "Disconnect"
- Visible when `ConnectionStatus` is connected, connecting, or reconnecting
- OnPressed: `connectionNotifierProvider.notifier.disconnect()`
- Color: `Colors.red[400]` border and text

## Interaction States

### Zero Button States

| State | Appearance |
|-------|-----------|
| `connected`, live data | Enabled, full opacity |
| `connected`, stale data (null) | Enabled per spec but stale opacity covers row — button also at 40% via AnimatedOpacity parent |
| Any other ConnectionStatus | Disabled (Material default disabled style) |

### FAB States

| ConnectionStatus | FAB icon | FAB color | Action |
|-----------------|---------|-----------|--------|
| idle / disconnected / error | `bluetooth_searching` | Blue 600 | startScan() |
| scanning | `stop` | Red 400 | stopScan() |
| connecting / connected | Hidden (not shown on scan screen while on instrument screen) | — | — |

Note: Phase 4 uses standalone `runApp()` without go_router. Navigation between screens is implemented via a simple `Navigator.push/pop` or a root `StatefulWidget` that switches screens based on `ConnectionStatus`. Phase 5 replaces this with go_router.

## Animation Contract

| Animation | Duration | Curve | Trigger |
|-----------|----------|-------|---------|
| Stale opacity fade | 300ms | Curves.easeOut | `instrumentDataProvider` emits null |
| Stale label appear | 300ms | Curves.easeOut | Same trigger, same AnimatedOpacity |
| Restore to live | 300ms | Curves.easeOut | `instrumentDataProvider` emits non-null |
| Chip color change | Instant (no animation) | — | ConnectionStatus changes |
| FAB icon swap | Default Hero animation (Flutter default) | — | Scan state changes |

No other animations in Phase 4.
