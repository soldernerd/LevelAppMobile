## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| BleManager.statePackets → StatePacket.parse | Raw bytes from BLE layer (or mock) cross into typed domain |
| ConnectionNotifier._handleStatusEvent | Single entry point for all connection state transitions |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-02 | Tampering | StatePacket.parse(bytes) inside statePackets subscriber | mitigate | Wrap in try/catch inside the packetSub listener; parse errors map to null or are swallowed with a debug log — never rethrow into the stream (RESEARCH.md Pitfall 5) |
| T-03-03 | Denial of Service | Auto-retry on StreamProvider error (Riverpod 3 default) | mitigate | StatePacket.parse errors are caught before reaching the stream, preventing Riverpod retry storm at 10 Hz mock rate |
| T-03-04 | Tampering | State machine race: concurrent connect/disconnect | accept | ConnectionNotifier is single authority; stream events serialize transitions; Dart is single-threaded |
| T-03-05 | Tampering | _packetController.add after close | mitigate | isClosed guard on every emit call (established pattern from MockBleManager CR-02) |
</threat_model>
