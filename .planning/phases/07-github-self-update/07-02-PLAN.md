## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub API → app | Untrusted JSON (tag_name, asset URLs) crosses into the parser |
| CDN → cache dir | Downloaded APK bytes cross into local storage |
| cache dir → installer | APK handed to the Android package installer |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-03 | Tampering | tag_name used in logic | mitigate | tag_name is never used as a filename (APK name hardcoded, D-10); leading 'v' stripped then int-parsed — non-numeric segments default to 0, no injection surface |
| T-07-04 | Tampering | MITM on API / download | mitigate | dio enforces HTTPS + TLS cert validation by default; download URL is a trusted GitHub asset host |
| T-07-05 | Spoofing | malicious APK | mitigate | Android verifies APK signature against the installed signing key at install time; mismatched signature is rejected by the OS |
| T-07-06 | Denial of Service | malformed/huge JSON, hung socket | mitigate | 10s send/receive timeout on the API GET; entire checkForUpdate wrapped in catch-all returning null (UPD-05) |
</threat_model>
